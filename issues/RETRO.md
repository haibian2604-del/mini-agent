## 交付清单

- Agent 循环：线性历史、结构化观察、异常即控制流（ Submitted / LimitsExceeded / ModelError / FormatError）
- 限额四件套：steps / consecutive format errors / cost（占位）/ tokens（探针验证后补上的真预算）
- 双执行后端：local 模块 + DockerEnvironment（容器内 timeout、workspace 挂载、崩溃遗留清理、死亡沙箱识别）
- 轨迹黑匣子：每轮落盘、防覆盖命名、`inspect` 回放器 + `--last`
- CLI：typer + rich，交互模式、裸调用默认交互、yaml 配置（extra=forbid）
- 45 个离线测试；README / .env.example 可让新人 5 分钟上手

## B 级问题登记与处理决定

原则：不阻塞当前使用、但会在错误场景烧钱/烧步数的，明确登记延后，不留「以为修了」的幻觉。

| # | 问题 | 处理决定 |
|---|---|---|
| B1 | 沙箱死亡（execute 返回 -2）后循环不终止，模型可能继续挣扎 | 延后观察：glm 实际收到 -2 观察的行为待一次真跑取证，再决定是识别 returncode 终止还是靠提示词 |
| B2 | cost_usd 在自定义端点恒为 0.0（litellm 无价目） | 已缓解：token 限额是真实预算。彻底解决需自维护价目表——YAGNI，暂不做 |
| B3 | SYSTEM_PROMPT 对无标注代码块的态度未同步（解析已放宽，提示词仍要求标 bash） | 保持现状：指令从严、解析从宽是有意设计 |
| B4 | 流式输出 / 并行 worktree / 真 SWE-bench Lite 样本 | 下一篇章，随时开工 |

## 本期三课

1. **假模型离线测试是循环逻辑的唯一可信防线**——try 包错位置、退出状态谎报、哨兵空子，全是它抓的；API 贵且慢，逻辑必须离线验。
2. **探针优于推测**——"cost 限额到底有没有效"不该看代码猜，一次几分钱的真调用直接定案。
3. **合约才是接口**——local 换 docker 零改动那一刻，之前所有"多此一举"的抽象都变成了回报。
